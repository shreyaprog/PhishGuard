About the Project

PhishGuard is a local phishing URL analysis and threat intelligence application. It helps users recognise potentially suspicious links by analysing URL characteristics and checking URLs against a locally maintained indicator list imported from CSV.

Phishing can expose login credentials and financial details, and may lead to unauthorised access to email, cloud storage, and other online services. PhishGuard provides a preliminary assessment with explanations; it does not open submitted URLs or guarantee that a URL is safe.

Project objective

Develop a practical, accessible tool that helps users identify suspicious links and check them against locally stored threat indicators.

Cloud security connection

Phishing prevention complements controls such as multi-factor authentication, least-privilege identity and access management, and security monitoring. PhishGuard is an educational tool and does not replace those controls or browser-based protection.
